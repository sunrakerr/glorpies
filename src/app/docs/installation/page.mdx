# installation

<Lead>One package, with an entry for each way of showing a face. Install it once; import only what you use.</Lead>

<Install />

## what each entry needs

| import | for | needs |
| --- | --- | --- |
| `glorpies/react` | the `<Glorpie>` component and a photo avatar with a fallback | React 18 or newer |
| `glorpies/element` | the `<glorpie-face>` web component | nothing |
| `glorpies` | `mount()` on your own canvas, stills, svg, seeds and colours | nothing |
| `glorpies/server` | image files: png, webp, jpeg, svg and gif | `@napi-rs/canvas` |
| `npx glorpies` | the command line | `@napi-rs/canvas` |

React and `@napi-rs/canvas` are optional peer dependencies: install them only for the entries that use them.

## images and the cli

Writing image files takes a real canvas outside the browser. [`@napi-rs/canvas`](https://github.com/Brooooooklyn/canvas) is a prebuilt one, with no system libraries to install:

<Install packages="glorpies @napi-rs/canvas" />

## without a bundler

The web component is also published as a single file, ready for a `<script>` tag:

```html
<script type="module" src="https://unpkg.com/glorpies"></script>
<!-- or -->
<script type="module" src="https://cdn.jsdelivr.net/npm/glorpies"></script>
```

Pin a version in production, as in `https://unpkg.com/glorpies@0.1.0`, so a release can't change your page under you.

## requirements

- **ESM only.** Every entry is an ES module; use `import`, not `require`.
- **Node 20 or newer**, for the server entry and the CLI. Bun and Deno work too.
- **TypeScript types are included.** `LookId`, `FaceState`, `Shape` and the option types are exported from `glorpies`.
