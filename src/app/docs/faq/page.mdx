# faq

<Lead>The questions people ask once they've seen a few faces.</Lead>

## is it really the same face everywhere?

Yes. A name hashes to the same seed everywhere, and the seed drives every decision with plain arithmetic, so a face is built the same in every browser, on every server, in every version. Tests pin the faces of known names, and a release that changed one would be a breaking release.

One honest footnote: functions like `Math.sin` round their last digit differently on ARM and x64 processors, so two machines can disagree about a coordinate by less than a millionth of a pixel. The face is the same; the bytes of a PNG might not be.

## how many faces are there? can two names share one?

9,007,199,254,740,992, one for each 53-bit seed: over a million for every person alive. Two names can land on the same seed, but rarely: among a million users, the chance that any two share a face is about 1 in 18,000.

## can someone choose their own face?

A name always gets the same face, so to let people choose, offer them a few (try `randomName()` for candidates, or a few seeds) and store the one they pick. Pass a seed number as `name` and you get that face.

## how heavy is it?

There are no dependencies. The drop-in script for `<glorpie-face>` is one file, loaded once for the whole page. Faces paint only when they come near the screen, share one animation loop, and stop moving when they're off screen or the tab is hidden.

## does it work with server rendering?

Yes. The React component renders a placeholder in the face's own colour on the server and paints on the client; the web component paints once it's on the page. For a face in HTML that never runs script, like an email, use an image from [your own route](/docs/server).

## can I use it commercially?

Yes. glorpies is MIT licensed: use it in anything, free, with no attribution in your interface required. The licence notice ships with the package.
