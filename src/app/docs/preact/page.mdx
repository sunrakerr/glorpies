# preact

## use it

```tsx title="UserBadge.tsx"
import { Glorpie } from 'glorpies/preact';

export function UserBadge({ user }) {
  return <Glorpie name={user.email} size={40} label={user.name} />;
}
```

<Preview>
  <Faces names={['ada@lovelace.dev', 'agent-47', 'grace@hopper.dev']} size={40} shape="circle" />
</Preview>

It takes every [option](/docs/options), plus `class` and `onError`. It's written for Preact itself, so there's no `preact/compat` to set up, and it renders on the server with `preact-render-to-string` as a placeholder in the face's own colour.

If your app already aliases React to `preact/compat`, `glorpies/react` works as well, photo avatars included.
