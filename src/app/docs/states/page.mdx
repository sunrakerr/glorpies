# states

A face can show what its owner is up to, which suits AI agents: you can pick one out of a crowded sidebar and read its status from its face, not from a badge beside it.

<StatesTable />

Each state changes the expression (mouth and brows, painted in the look's own hand), how the head moves, and adds a mark by the head that still reads at 32px.

```tsx title="Agents.tsx" tab="react"
{agents.map((agent) => (
  <li key={agent.id}>
    <Glorpie name={agent.id} state={agent.status} size={36} label={`${agent.name}: ${agent.status}`} />

  </li>
))}
```

```vue title="Agents.vue" tab="vue"
<li v-for="agent in agents" :key="agent.id">
  <Glorpie :name="agent.id" :state="agent.status" :size="36" :label="`${agent.name}: ${agent.status}`" />
  {{ agent.name }}
</li>
```

```svelte title="Agents.svelte" tab="svelte"
{#each agents as agent (agent.id)}
  <li>
    <Glorpie name={agent.id} state={agent.status} size={36} label="{agent.name}: {agent.status}" />
    {agent.name}
  </li>
{/each}
```
