# server images

For emails, link previews, chat apps and anywhere else that wants a URL rather than a component, serve faces as image files from your own app.

<Install packages="glorpies @napi-rs/canvas" />

`@napi-rs/canvas` is a prebuilt canvas for Node, with no system libraries to install.

## a route

<CodeGroup>

```ts title="app/api/face/route.ts" tab="next.js"
import { faceRoute } from 'glorpies/server';

export const { GET } = faceRoute();
```

```ts title="src/routes/api/face/+server.ts" tab="sveltekit"
import { createFaceHandler } from 'glorpies/server';

const faces = createFaceHandler();

export const GET = ({ request }) => faces(request);
```

```ts title="server/api/face.ts" tab="nuxt"
import { createFaceHandler } from 'glorpies/server';

const faces = createFaceHandler();

```

```ts title="src/pages/api/face.ts" tab="astro"

```

```ts title="server.ts" tab="express"
import express from 'express';
import { nodeFaceHandler } from 'glorpies/server';

const app = express();
app.get('/api/face', nodeFaceHandler());
```


Then ask for faces by URL:

```text
/api/face?name=agent-47
/api/face?name=agent-47&look=ink&size=128&shape=circle&format=webp
/api/face?name=agent-47&state=thinking&format=gif
```

## query

| parameter | values | default |
| --- | --- | --- |
| `name` | any string (required) | |
| `look` | `auto` or a [look](/docs/looks) | `auto` |
| `size` | 16 to 1024 pixels; gifs up to 320 | `256` |
| `shape` | `circle`, `squircle`, `rounded`, `square`; outside is transparent | `square` |
| `state` | `idle`, `thinking`, `working`, `waiting`, `blocked`, `done` | `idle` |
| `background` | `false` for only the face | `true` |
| `format` | `png`, `webp`, `jpeg`, `svg`, `gif` | `png` |
| `loop` | seconds a gif runs before it repeats, 1 to 8 | `3` |
| `fps` | gif frames per second, 4 to 30 | `15` |

Unknown values fall back to the defaults, so a typo still gets a face.

## options

Every handler takes defaults for the query, and limits:

```ts
faceRoute({
  look: 'ink',
  size: 128,
  maxSize: 512,                           // the largest ?size= (default 1024)
  maxName: 128,                           // the longest ?name= (default 256)
  cacheControl: 'public, max-age=86400',  // default: a year, for browsers and CDNs
});
```

## caching and safety

- The same URL always gives the same image, so responses are cached for a year by browsers and CDNs. Behind a CDN, each face is painted once.
- Sizes are clamped and long names refused (414), so no request can ask for an enormous image. A gif's frames are capped too.
- SVG is sent with a Content-Security-Policy that runs no script and loads nothing, and every response has `X-Content-Type-Options: nosniff`.
- When painting fails, the details go to your server's log; the response only says that it failed.
- Rendering is CPU work. On a public route, add your host's rate limiting, as for any image endpoint.

## without a route

```ts
import { faceGIF, renderImage } from 'glorpies/server';

const { body, type } = await renderImage('agent-47', { look: 'sticker', size: 256, format: 'webp' });
const gif = await faceGIF('agent-47', { state: 'done', size: 128, loop: 3 });
```

Everything in `glorpies/server` sets up the native canvas itself. To draw with `faceCanvas()` or `faceSVG()` from `glorpies` on a server, call `await useNativeCanvas()` once first.

<Note>This site answers the same URLs at `/api/face`, for trying things out. It's a demo, not a CDN for your app: host the route yourself for anything real.</Note>
