# looks

The same alien, in a different hand: 21 paintings for faces shown large, and 8 avatar looks that still read at 16px. Type a name to see yours.

<LooksGrid />

## auto

The default, `auto`, picks for you: the watercolour at 72px and up, and the `ink` badge below, where a painting's brushwork would turn to mush. Set `look` to choose one yourself.

## the list

`LOOKS` has every look, with its name and whether it's a painting or an avatar look:

```ts
import { FULL_LOOKS, LOOKS, SMALL_LOOKS } from 'glorpies';

LOOKS.map((look) => look.id); // ['watercolour', 'atkinson', 'bayer', …]
```
