## use it

```vue title="UserBadge.vue"
<script setup>
import { Glorpie } from 'glorpies/vue';

defineProps(['user']);
</script>

<template>
  <Glorpie :name="user.email" :size="40" :label="user.name" />
</template>
```

<Preview>

Takes every [option](/docs/options) as a prop. Bind `:background="false"`: the static `background="false"` passes a string, which is truthy.

## nuxt

No configuration. On the server the component renders a placeholder in the face's background colour, at its final size; it paints after hydration.

```vue title="pages/team.vue"
<script setup>
import { Glorpie } from 'glorpies/vue';

const { data: team } = await useFetch('/api/team');
</script>

<template>
  <Glorpie v-for="person in team" :key="person.id" :name="person.email" :size="32" />
</template>
```

## errors

If a face fails to paint, the component emits `error`. Without a listener, the error goes to `console.error`.

```vue
<Glorpie :name="user.id" @error="report" />
```
