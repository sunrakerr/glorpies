# solid

<Install />

## use it

```tsx title="UserBadge.tsx"
import { Glorpie } from 'glorpies/solid';

export function UserBadge(props) {
  return <Glorpie name={props.user.email} size={40} label={props.user.name} />;
}
```

<Preview>

</Preview>

Takes every [option](/docs/options), plus `class` and `onError`. Every prop is reactive; changing one updates the face without remounting it.

```tsx
const [status, setStatus] = createSignal('working');

<Glorpie name="agent-47" state={status()} />
```

## solidstart

No configuration. On the server the component renders a placeholder in the face's background colour, at its final size; it paints after hydration.
