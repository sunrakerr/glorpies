## errors

A failed paint is reported once per face, and goes to `console.error` unless handled:

| where | how |
| --- | --- |
| React, Svelte, Solid, Preact | `onError={(error) => …}` |
| Vue | `@error="…"` |
| `<glorpie-face>` | a cancellable `glorpie-error` event; `preventDefault()` suppresses the log |
| `mount()` | the `onError` option |
