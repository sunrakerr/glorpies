# options

The components share the options below, as do the attributes and properties on `<glorpie-face>`. The [image route](/docs/server) and [CLI](/docs/cli) accept the options that apply to image files.

A numeric `name` is a seed; a string is hashed into one. `name={42}` and `name="42"` are different faces. On the element, use `face.name = 42` for a seed: HTML attributes, URL query parameters and CLI arguments are strings.

## errors

A failed paint is reported once per face, and goes to `console.error` unless handled:

| where | how |
| --- | --- |
| React, Svelte, Solid, Preact | `onError={(error) => …}` |
| Vue | `@error="…"` |
| `<glorpie-face>` | a cancellable `glorpie-error` event; `preventDefault()` suppresses the log |
| `mount()` | the `onError` option |
