## use it

```tsx title="UserBadge.tsx"
import { Glorpie } from 'glorpies/react';

export function UserBadge({ user }) {
  return <Glorpie name={user.email} size={40} label={user.name} />;
}
```

It takes every [option](/docs/options), plus `className`, `style` and `onError`. React 18 and 19 both work, in any setup: Vite, Next.js, Remix, React Router.

## photo avatars

People with a photo get their photo; everyone else, and anyone whose photo is still loading or fails, gets their face. `Avatar` sets the size and shape for both.

```tsx title="Avatar.tsx"
import { Avatar, AvatarFallback, AvatarImage } from 'glorpies/react';

<Avatar size={56}>
  <AvatarImage src={user.photoUrl} alt={user.name} />
  <AvatarFallback name={user.email} />
</Avatar>
```

<Preview>
  <AvatarDemo />
</Preview>

`AvatarImage` is an `<img>`: `srcSet`, `onLoad` and `onError` work as usual. `AvatarFallback` takes every `Glorpie` prop but `size` and `shape`.

## server rendering

`glorpies/react` starts with `'use client'`, so in Next.js it works straight from server components, with no wrapper. On the server each face renders as a placeholder in its own colour, sized and cropped, so nothing shifts when it paints.

## errors

A face that can't be painted calls `onError`; without one, the error is logged.

```tsx
<Glorpie name={user.id} onError={(error) => report(error)} />
```
