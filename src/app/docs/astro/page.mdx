## in an astro component

Astro passes custom elements through untouched. Register the element from a `<script>`, which Astro bundles for the client:

```astro title="UserBadge.astro"
---
const { email } = Astro.props;
---

<glorpie-face name={email} size="40" style="width: 40px; height: 40px"></glorpie-face>

<script>
  import 'glorpies/element';
</script>
```

<Preview>
  <Faces names={['ada@lovelace.dev', 'agent-47', 'grace@hopper.dev']} size={40} shape="circle" />
</Preview>

Every [option](/docs/options) is an attribute. The inline size reserves the space until the element upgrades.

## in a framework island

If you already use React, Vue, Svelte, Solid or Preact in Astro, use that component as an island. It server-renders a placeholder, and with `client:visible` it hydrates only when scrolled into view:

```astro title="Team.astro"
---
import { Glorpie } from 'glorpies/react';
---

<Glorpie client:visible name="ada@lovelace.dev" size={40} />
```

## as an image

For zero client JavaScript, serve faces from an [image route](/docs/server) and use an `<img>`.
