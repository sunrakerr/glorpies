# React starter

A standalone Vite app using the published `glorpies/react` component. Changing the name or look updates the same avatar; tapping it makes it wobble.

Use Node 22.12+ (or a newer supported LTS):

```sh
npm ci
npm run dev
```

Open the local URL printed by Vite. `npm run build` creates a production app in `dist/`; `npm run preview` serves that build locally.

Start with `src/main.jsx`. See the [React guide](https://glorpies.sunrakerr.dev/docs/react) for all props, photo fallbacks and Next.js.
