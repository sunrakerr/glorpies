# Vanilla JavaScript starter

A standalone Vite app using `<glorpie-face>`, without a UI framework. One import registers the element; ordinary input events update its name and look.

Use Node 22.12+ (or a newer supported LTS):

```sh
npm ci
npm run dev
```

Open the local URL printed by Vite. `npm run build` creates a production app in `dist/`; `npm run preview` serves that build locally.

Start with `index.html` and `src/main.js`. See the [HTML & JavaScript guide](https://glorpies.sunrakerr.dev/docs/html) for all attributes and using your own canvas.
